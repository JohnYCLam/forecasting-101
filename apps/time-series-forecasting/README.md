# Time-series forecasting — core course

Published on main: 1. Basic Forecast; 2. ARIMA and Selection; 3. Metrics and Validation; 4. Volatility and GARCH; 5. VARIMA and Connected Series.

This app retains its existing fitted-model datasets and shared chart controls. Source notebooks and experimental reviews are kept separately as local research. Public topic1_data.json through topic5_data.json are unchanged by the site migration.

Run npm run lint, npm test, and npm run build from this app, or use the combined root commands. Data generators remain under scripts/generators/ and can be invoked with npm run data:topicN.

Section 6, its dataset, generators, and development/review documents live on development/forecasting-section-6. The shared site theme is in ../../site/theme.css.
